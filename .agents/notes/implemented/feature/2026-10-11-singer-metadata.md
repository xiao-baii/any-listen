# Agent Note: 公共扩展开放与独立歌手元数据

Status: implemented

## Problem

公共扩展安装和发布写死两个 ID，歌手页面已接入接口但实际元数据扩展没有实现。管理员不能安装独立歌手扩展。

## Decision

删除 ID 和数量限制，按安装列表发布包、配置和标准 storage，保留管理员权限、公共宿主能力边界和回滚。禁用扩展不执行。LX 专用就绪检查仅在启用时执行。

独立 singer-metadata 扩展实现五平台 singerSearch / singer，复用现有页面与播放数据契约，手动导入 alix 后发布，不建设商店、预装和自动升级机制。

歌手搜索沿用歌曲、歌单的左侧来源布局，不单独改为窄屏横排。扩展 0.1.1 的来源声明顺序对齐 Online Metadata：酷狗、酷我、网易云、QQ、咪咕；直接调整声明，不增加页面排序规则。

扩展 0.1.2 使用现有 manifest 翻译键与 i18n 目录，平台名称对齐 Online Metadata 的简体中文、英文，补齐繁体中文；打包包含语言文件。无需主程序改动，不在页面硬编码翻译。

## Alternatives considered

修改 Online Metadata 可以复用其平台适配，但会维护外部扩展分支；采用独立扩展并保持现有资源契约。自动安装可减少用户操作，但需要处理草稿与正式版本独立升级；本次选择手动导入发布。固定 ID 能缩小首版验证范围，但阻止正常资源扩展，改为现有公共能力检查。

## Testing

0.1.2 的实际 ALIX 安装测试验证简体中文、英文和繁体中文的五个平台名称，安装更新发布回归及账号类型检查通过。

账号、共享资源、播放器、歌单、启动恢复、歌手、官方扩展、新扩展样例及 ALIX 安装共 61 项测试通过，覆盖任意扩展和零扩展发布、配置与 storage 快照、禁用、个人能力隔离、回滚和旧版本恢复。Web、桌面源码构建及账号类型检查通过。

五平台真实搜索与作品分页通过，实际扩展宿主也分别成功调用搜索和作品接口。浏览器验证来源切换、详情、翻页、搜索空结果和来源不可用提示；队列失败保留由现有歌手回归覆盖。歌曲转换检查播放所需平台字段，但未取得用户实际播放音源，尚未完成五平台实际解析和出声验收。

本机 DNS Fake-IP 会把平台域名解析到保留地址；隔离测试宿主通过既有 SINGER_TEST_ORIGINS 参数允许六个精确来源，生产网络检查不变。实时接口测试独立运行，不让离线样例代替真实验证。

## Consequences

管理员可独立安装、更新和发布歌手扩展，不再依赖原两个扩展。外部平台接口可能限流或变更，不能用模拟结果声称实际可用。共享宿主仍不支持个人播放器和歌单能力。运行期临时数据不回写管理员草稿。包通过 npm run build:singer-extension 重建，保持手动安装发布。
