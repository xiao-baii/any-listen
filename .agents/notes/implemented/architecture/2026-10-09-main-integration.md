# Agent Note: 上游更新与多用户隔离适配

Status: implemented

## Problem

main 3734f1a9 的快捷键、命令和歌词接口更新与多用户实例冲突；上游自动同步开关没有覆盖独立账号同步器。

## Decision

普通 merge 合入该提交，保留账号存储、事件、资源与缓存实例。对齐上游快捷键契约和 getStore 命名导出，播放命令限定当前账号，扩展命令仍限管理员。多用户模式不开放本地库、远程文件库或 WebDAV 同步。

已有和新建歌单缺少 autoSync 均视为关闭；自动任务在执行和提交结果时检查开关，手动同步不受限制。无需批量迁移歌单。歌手独立队列保持现有契约，见 [歌手播放](../../implemented/feature/2026-10-09-singer-playback.md)。检索结果仅该笔记部分相关，保留并互相独立。

## Alternatives considered

直接采用上游模块可以减少适配，但会恢复全局状态并破坏账号隔离，因此将上游行为移入已有实例。保留旧歌单自动同步可减少升级变化，但用户明确选择统一默认关闭，因此缺字段也关闭。

## Testing

账号隔离、快捷键配置与启停及重启保存、歌词转换、同步开关与关闭时的排队/在途任务测试通过。普通命令在前端当前账号执行，executeCommand RPC 仍受原管理员边界约束，草稿扩展不因上游命令重构获得运行权限。官方扩展兼容、歌手和既有回归测试通过。浏览器验证桌面及 320/375/430px 下的筛选、快捷键、收藏菜单和同步设置，并验证歌单及排行榜保存普通副本。同步完成后同时更新 songCount，避免旧元数据覆盖新歌曲数。

## Consequences

不恢复已裁剪入口，无数据库表迁移；旧歌单升级后需主动开启自动同步。上游内部扩展构造补齐 readme，字符编码检测处理新版依赖允许的 null。Electron 路径仅在启动开发窗口时读取，避免新版 Electron 在纯构建时下载二进制；Web 与桌面源码构建均通过。全量前端检查为 168 错误、17 警告（原 171/17），与旧日志比较无新的错误消息，未扩大修复已有音频 JS 和依赖声明。真实歌手音源依赖外部扩展适配，不作为此次已验收能力。
